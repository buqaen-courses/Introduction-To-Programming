## 🎯 Course Overview

Welcome to **Introduction to Programming**, a comprehensive journey from computer fundamentals to professional software development. This course transforms complete beginners into confident programmers capable of building real-world applications.

This course bridges the gap between theoretical computer science concepts and practical programming skills. You'll learn not just how to code, but how computers work, how to think algorithmically, and how to develop software professionally.

---

## 📚 Learning Objectives

By the end of this course, you will be able to:

### **Technical Skills**
- **Understand Computer Fundamentals**: Hardware, software, memory, operating systems
- **Master Data Representation**: Bits, bytes, binary, text encoding, data structures
- **Apply Algorithmic Thinking**: Problem decomposition, IPO model, algorithm analysis
- **Write Clean Python Code**: Variables, functions, control flow, error handling
- **Build Complete Applications**: File I/O, modules, testing, project development

### **Professional Skills**
- **Systematic Problem Solving**: Breaking complex problems into manageable steps
- **Code Organization**: Modular design, documentation, best practices
- **Error Handling**: Debugging, testing, robust software development
- **Project Management**: Planning, implementation, deployment of software projects
- **Career Readiness**: Portfolio development, interview preparation, further learning paths

## 🏗️ Course Structure

### **Module 1: Computers and Programs** (2 sessions)
**Foundation Layer** - Understanding how computers work before learning to program them

- **Session 1**: Computer Fundamentals - CPU, RAM, Storage, I/O, Hardware vs Software
- **Session 2**: Code Translation & Execution - Source code, machine code, compilation, interpretation

**Key Concepts**: Process lifecycle, memory architecture, file systems, binary representation, operating systems

### **Module 2: Digital Information** (4 sessions)
**Data Layer** - How information is represented and stored in computers

- **Session 3**: Bits, Bytes & Data Fundamentals - Digital vs analog, data storage units
- **Session 4**: Number Systems - Binary, hexadecimal, decimal conversions
- **Session 5**: Binary Arithmetic - Addition, subtraction, bitwise operations
- **Session 6**: Text Representation - Character encoding, strings, Unicode

**Key Concepts**: Information theory, number systems, arithmetic operations, text encoding

### **Module 3: Algorithmic Thinking** (3 sessions)
**Logic Layer** - Developing systematic problem-solving skills

- **Session 7**: Input-Process-Output Model - Fundamental programming model, state
- **Session 8**: Algorithm Characteristics & Types - FIDEO framework, algorithm analysis
- **Session 9**: Pseudocode & Flowcharts - Structured English, control structures, translation

**Key Concepts**: IPO model, algorithm analysis, pseudocode, control flow

### **Section 0: Flowcharts** (optional primer, 6 lessons)
**Orientation Layer** - Designing algorithms visually before Session 1

- **Lesson 1**: Why Draw Before You Code
- **Lesson 2**: The Six Symbols and the Five Laws
- **Lesson 3**: The Three Control Patterns
- **Lesson 4**: Loops and Trace Tables
- **Lesson 5**: Design Method and Review Checklist
- **Lesson 6**: Workshop - Three Briefs

See [`section-0-flowcharts/`](section-0-flowcharts/README.md)

### **Module 4: Python Essentials** (7 sessions)
**Programming Layer** - Learning Python programming from basics to intermediate concepts

- **Session 10**: Python Environment & First Steps - Installation, REPL, basic syntax
- **Session 11**: Variables & Data Types - Types, type conversion, variable scope
- **Session 12**: Input/Output & Expressions - Console I/O, operators, evaluation
- **Session 13**: Decision Making - if/elif/else, boolean logic, nested conditionals
- **Session 14**: Loops - while/for loops, loop control, iteration patterns
- **Session 15**: Working with Strings - String operations, formatting, text processing
- **Session 16**: Collections - Lists, dictionaries, sets, tuples

**Key Concepts**: Python syntax, data structures, control flow, string manipulation

### **Module 5: Software Development** (6 sessions)
**Professional Layer** - Building complete, robust applications

- **Session 17**: Functions - Reusable code blocks, parameters, modular design
- **Session 18**: Error Handling & Debugging - Exceptions, debugging techniques, common errors
- **Session 19**: File I/O - Reading/writing files, data persistence, file processing
- **Session 20**: Modules & Organization - Multi-file programs, code organization, project structure
- **Session 21**: Mini-Project 1 - Complete data processing application development
- **Session 22**: Capstone Projects - Course review, personal projects, portfolio development

**Key Concepts**: Software engineering, project development, testing, documentation

### دوره برنامه‌نویسی مقدماتی - دانشگاه بزرگمهر قائنات

این دوره آموزشی جامع، شما را از پایه‌های کامپیوتر تا توسعه نرم‌افزار حرفه‌ای راهنمایی می‌کند. این دوره نه تنها آموزش برنامه‌نویسی، بلکه تفکر سیستمی و مهارت حل مسئله را نیز تقویت می‌کند.

### اهداف یادگیری:
- درک بنیادی کامپیوتر و نحوه عملکرد آن
- تسلط بر نمایش داده‌ها و ساختارهای اطلاعاتی
- تفکر الگوریتمی و حل مسئله سیستمی
- مهارت برنامه‌نویسی پایتون از پایه تا پیشرفته
- توسعه نرم‌افزار کامل و حرفه‌ای

### ساختار دوره (۵ ماژول):

#### ماژول ۱: کامپیوتر و برنامه‌ها
- مبانی کامپیوتر: سخت‌افزار، نرم‌افزار، حافظه، سیستم عامل
- ترجمه کد: کد منبع، کد ماشین، کامپایل، تفسیر

#### ماژول ۲: اطلاعات دیجیتال
- بیت و بایت، سیستم‌های عددی
- محاسبات باینری، نمایش متن
- تبدیل داده‌های آنالوگ به دیجیتال

#### ماژول ۳: تفکر الگوریتمی
- مدل ورودی-پردازش-خروجی
- ویژگی‌ها و انواع الگوریتم‌ها
- شبه‌کد و ساختارهای کنترلی

#### ماژول ۴: essentials پایتون
- محیط برنامه‌نویسی پایتون
- متغیرها، انواع داده، کنترل جریان
- رشته‌ها، مجموعه‌ها، برنامه‌نویسی تعاملی

#### ماژول ۵: توسعه نرم‌افزار
- توابع و برنامه‌نویسی مدولار
- مدیریت خطا و اشکال‌زدایی
- کار با فایل‌ها، پروژه‌های کامل

### مواد آموزشی:
- **۲۲ جلسه سخنرانی**: مطالب آماده تدریس
- **۶۰+ مقاله مفهومی**: توضیحات عمیق و مثال‌های عملی
- **تمرین‌های عملی**: برنامه‌نویسی کاربردی
- **پروژه‌های عملی**: توسعه نرم‌افزار کامل
- **بخش صفر (اختیاری)**: [شش درس مقدمه فلوچارت](section-0-flowcharts/README_FA.md) برای طراحی الگوریتم‌ها پیش از کدنویسی

### پیش‌نیازها:
- سواد کامپیوتر پایه (استفاده از موس و کیبورد)
- کنجکاوی و علاقه به یادگیری
- ۱۰-۱۵ ساعت وقت مطالعه هفتگی

### مزایای دوره:
- **آموزش گام‌به‌گام**: از پایه تا پیشرفته
- **تمرکز بر مفاهیم**: نه فقط کدنویسی، بلکه تفکر برنامه‌نویسی
- **آماده‌سازی شغلی**: مهارت‌های مورد نیاز بازار کار
- **انعطاف‌پذیری**: یادگیری خودخوان یا با راهنمایی
