# جلسه ۱۱: متغیرها و انواع داده پایه (int، float، bool، str)

## مرور جلسه

جلسه قبل پایتون را اجرا کردید و چیزهایی چاپ کردید. حالا به آن مقادیر نام می‌دهیم و می‌پرسیم هر نام چه نوع چیزی در دست دارد. این جلسه متغیرها را به‌عنوان برچسبی روی مقدار معرفی می‌کند، چهار نوع داده‌ای را که مدام استفاده خواهید کرد (`int`، `float`، `bool`، `str`) و تبدیل نوع را، از جمله دلیلی که `input()` هرچه بگیرید رشته تحویل می‌دهد.

## اهداف یادگیری کلیدی

در پایان این جلسه می‌توانید:

- **بسازید** متغیر و با `=` به آن مقدار بدهید
- **به‌درستی استفاده کنید** از `int`، `float`، `bool` و `str`
- **بررسی کنید** نوع یک مقدار را با `type()`
- **تبدیل کنید** بین انواع به‌صورت صریح و نتیجه را پیش‌بینی کنید
- **پرهیز کنید** از رایج‌ترین اشتباهات مبتدی، از جمله بازنویسی نام‌های توکار

## متغیر یک برچسب است، نه یک جعبه

رایج‌ترین برداشت نادرست در آغاز این است که متغیر ظرفی است که مقداری را نگه می‌دارد. مدل بهتر این است که متغیر برچسبی است که به مقداری که از قبل وجود دارد چسبیده است:

```python
age = 25
```

این را بخوانید: «نام `age` به مقدار ۲۵ اشاره می‌کند». دوباره انتساب دادن، برچسب را *جابه‌جا* می‌کند؛ جعبه‌ای را تغییر نمی‌دهد:

```python
age = 25        # age به ۲۵ اشاره می‌کند
age = 30        # age حالا به ۳۰ اشاره می‌کند؛ ۲۵ جای دیگری دست‌نخورده است
```

به همین دلیل دو متغیر می‌توانند به یک مقدار اشاره کنند، و به همین دلیل تغییر دادن یک لیست بعداً روی هر دو اثر می‌گذارد. در جلسه ۱۶ این را کامل می‌بینید.

## چهار نوعی که الان لازم دارید

```
    ┌──────────────────────────────────────────────────────────────┐
    │  TYPE      EXAMPLE      NOTES                               │
    ├──────────────────────────────────────────────────────────────┤
    │  int      25, -7, 0     Whole numbers. No decimal point.    │
    │  float    3.14, -0.5    Decimal numbers. Any point → float. │
    │  bool     True, False   Exactly two values. Capital letters.│
    │  str      "Ali", 'hi'    Text in quotes. Can hold anything.  │
    └──────────────────────────────────────────────────────────────┘
```

به حروف بزرگ `True` و `False` دقت کنید. `true` و `false` نیستند. این یکی از رایج‌ترین اشتباهات هفته اول است.

## بررسی نوع

`type()` می‌گوید یک مقدار چه نوعی است. این ابزاری برای دیباگ است که مدام استفاده خواهید کرد:

```python
print(type(25))        # <class 'int'>
print(type(25.0))      # <class 'float'>
print(type(True))      # <class 'bool'>
print(type("25"))      # <class 'str'>
```

به خط آخر دقت کنید. `25` و `"25"` هنگام چاپ تقریباً یکسان به نظر می‌رسند، ولی دو نوع کاملاً متفاوت‌اند. اینجا بذر خطاهای نوعی جلسه ۱۲ کاشته می‌شود.

## تبدیل نوع صریح است

برای تغییر نوع، آن نوع را مثل یک تابع صدا بزنید:

```python
age_text = "25"          # str
age_number = int(age_text)   # int

print(age_number + 5)   # 30      works
print(age_text + "5")   # 255     concatenates!
```

خط دوم تله است. `"25" + "5"` می‌شود `255`، چون برای رشته‌ها `+` یعنی چسباندن. `25 + 5` می‌شود `30`، چون برای عددها `+` یعنی جمع. یک عملگر، نوع‌های داده متفاوت، معنای متفاوت.

## مفاهیم اصلی

- **انتساب**: `name = value` یک نام را به یک مقدار می‌بندد
- **م‌تایپینگ پویا**: نوع را اعلام نمی‌کنید؛ خودِ مقدار نوع را حمل می‌کند
- **`type()`**: نشان می‌دهد یک مقدار واقعاً چه نوعی است
- **تبدیل صریح**: `int()`، `float()`، `str()`، `bool()` به‌عنوان تابع
- **درستی‌سنجی `bool()`**: صفر، رشته خالی و مجموعه خالی `False` هستند
- **قواعد نام‌گذاری**: حرف، رقم و زیرخط؛ نمی‌تواند با رقم شروع شود
- **پنهان‌سازی**: بازنویسی توکاری مثل `list` یا `str` بعداً همه‌چیز را خراب می‌کند

## اشتباهات رایج مبتدی

| اشتباه | چه اتفاقی می‌افتد |
|--------|-------------------|
| `true` به‌جای `True` | خطای `NameError`. پایتون به بزرگی و کوچکی حروف حساس است. |
| بازنویسی `list` یا `str` | کد شما بعداً به شکل گیج‌کننده‌ای خراب می‌شود |
| استفاده از نتیجه `input()` در حساب | `TypeError`. همیشه یک `str` است |
| `age = age + 1` «کار نمی‌کند» | کار می‌کند؛ اگر نام را اشتباه تایپ کنید `age` هنوز به مقدار قبلی اشاره می‌کند |
| استفاده از `=` جای `==` | `=` انتساب می‌دهد، مقایسه نمی‌کند |

## فعالیت‌های کارگاه

۱. **کارت اطلاعات شخصی.** برای نام، سن، قد و اینکه آیا برنامه‌نویسی را دوست دارید متغیر بسازید. هرکدام را در یک خط چاپ کنید، بعد هر چهار را با یک `print()` چاپ کنید.
۲. **حدس نوع.** همکلاسی‌تان ده مقدار به شما نشان می‌دهد. پیش از اجرای هرچیزی، `type()` هرکدام را بنویسید. بعد بررسی کنید و هر موردی را که اشتباه زدید دوباره نگاه کنید.
۳. **تله رشته.** تلاش کنید ثابت کنید `"20"` و `20` یکی نیستند. بعد آن دو چیز متفاوتی را پیدا کنید که کار می‌کنند.
۴. **کلینیک تبدیل.** سه رشته از `input()` بگیرید و برنامه‌ای بسازید که بدون کرش روی آن‌ها حساب انجام دهد.

## تکالیف

- **تمرین متغیر**: سه اسکریپت کوچک درباره یک محصول، یک فیلم و یک شهر، هرکدام با دست‌کم پنج متغیر از انواع مختلف.
- **پیش‌بینی خروجی**: شش قطعه‌کد کوتاه بدهید. دقیقاً بنویسید هرکدام چه چیزی چاپ می‌کند. بعد اجرا کنید و هر موردی را که اشتباه زدید علامت بزنید.
- **چالش نوع**: عمداً کدی بنویسید که یک رشته را به یک عدد جمع کند، `TypeError` را با دقت بخوانید، و دو روش متفاوت برای رفعش به کار ببرید.
- **تأمل**: یک بند به زبان خودتان بنویسید که `=` چه می‌کند.

## نکات کلیدی

- متغیر نامی است که به یک مقدار بسته شده، و انتساب دوباره همان اتصال را عوض می‌کند.
- پایتون نیازی به اعلان نوع ندارد؛ خودِ مقدار نوعش را حمل می‌کند.
- `type()` نخستین ابزار دیباگ شماست.
- تبدیل صریح است: باید آن را بخواهید.
- `+` برای رشته و عدد معنای متفاوتی دارد، و به همین دلیل `input()` پیش از حساب نیاز به تبدیل دارد.
