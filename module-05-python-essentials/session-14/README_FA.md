# جلسه ۱۴: حلقه‌ها، while و for

## مرور جلسه

برنامه‌ای که هر خط را دقیقاً یک بار اجرا کند، کار زیادی نمی‌تواند بکند. حلقه‌ها اجازه می‌دهند یک بلوک کد بارها اجرا شود، و همین چیزی است که یک اسکریپت را به چیزی تبدیل می‌کند که می‌تواند به‌جای یک آیتم، فهرستی هزارتایی را پردازش کند. این جلسه `for` را برای پیمایش یک دنباله، `while` را برای تکرار تا تغییر یک شرط، و دو کلیدواژه‌ای را پوشش می‌دهد که اجازه می‌دهند زودتر از حلقه خارج شوید: `break` و `continue`.

## اهداف یادگیری کلیدی

در پایان این جلسه می‌توانید:

- **بنویسید** حلقه‌های `for` روی بازه‌ها و دنباله‌ها
- **بنویسید** حلقه‌های `while` با شرطی که تضمیناً پایان می‌یابد
- **به‌کار ببرید** `break` و `continue` برای کنترل جریان حلقه
- **انتخاب کنید** آگاهانه بین `for` و `while`
- **پرهیز کنید** از حلقه‌های بی‌نهایت و خطاهای یکی‌زیاد
- **ردیابی کنید** تکرارهای یک حلقه را با دست روی کاغذ

## دو حلقه، دو کاربرد

```
    for      «این کار را برای هر آیتم این دنباله انجام بده»
              از قبل می‌داند چند بار اجرا می‌شود

    while    «تا وقتی یک چیز درست است، ادامه بده»
              تعدادش را از قبل نمی‌دانی
```

تمام تفاوت همین است. اگر می‌دانید روی چه چیزی پیمایش می‌کنید، از `for` استفاده کنید. اگر تا تغییر دنیا تکرار می‌کنید، `while`.

## حلقه for

```python
for i in range(5):
    print(i)
# 0 1 2 3 4      <- دقت کنید: از صفر شروع می‌شود، قبل از ۵ می‌ایستد

for name in ["Sara", "Ali", "Reza"]:
    print(name)
# Sara Ali Reza

for char in "Python":
    print(char)
# P y t h o n
```

`range(5)` پنج مقدار تولید می‌کند: از ۰ تا ۴. همین رفتار یکی‌زیاد، رایج‌ترین شگفتی مبتدی‌هاست. `range(1, 6)` به شما ۱ تا ۵ را می‌دهد.

## حلقه while

```python
count = 0
while count < 3:
    print(count)
    count += 1
# 0 1 2
```

شرط **پیش** از هر تکرار بررسی می‌شود. اگر هرگز نادرست نشود، حلقه هرگز تمام نمی‌شود. این خطرناک‌ترین چیز درباره `while` است:

```python
# هرگز تمام نمی‌شود - count تغییر نمی‌کند
count = 0
while count < 3:
    print(count)
```

راه‌حل این است که مطمئن شوید چیزی داخل حلقه به سمت نادرست شدن شرط حرکت می‌کند. اگر مطمئن نیستید یک حلقه `while` چطور تمام می‌شود، به‌جایش از حلقه `for` استفاده کنید.

## break و continue

```python
for i in range(10):
    if i == 5:
        break          # کلاً از حلقه خارج شو
    print(i)
# 0 1 2 3 4

for i in range(5):
    if i == 2:
        continue       # این تکرار را رد کن، ادامه بده
    print(i)
# 0 1 3 4
```

یک نکته ظریف که ارزش دانستن دارد: `break` در حلقه‌ای که داخل حلقه دیگر است، فقط حلقه *داخلی* را می‌شکند.

## مفاهیم اصلی

- **`for` یک دنباله را پیمایش می‌کند** با تعداد مشخص
- **`range(n)` از ۰ تا n-1 می‌دهد**، که منشأ خطای یکی‌زیاد است
- **`while` تا برقرار بودن شرط تکرار می‌کند** و به به‌روزرسانی شما وابسته است
- **`break` از حلقه خارج می‌شود**؛ `continue` به تکرار بعدی می‌پرد
- **`enumerate()`** اندیس و مقدار را با هم می‌دهد
- **حلقه‌های تودرتو ضرب می‌شوند**: دو حلقه روی ۱۰ آیتم یعنی ۱۰۰ تکرار
- **الگوی انباشتگر**: قبل از حلقه مقداردهی اولیه کن، داخل حلقه به‌روزرسانی کن

## اشتباهات رایج مبتدی

| اشتباه | نتیجه |
|--------|-------|
| شرط `while` که تغییر نمی‌کند | حلقه بی‌نهایت، یا برنامه‌ای که هنگ کرده |
| فراموش کردن `count += 1` | همان حلقه بی‌نهایت، با کد متفاوت |
| `range(1, 10)` وقتی منظورتان ۱ تا ۱۰ بود | آخرین آیتم از دست می‌رود |
| تورفتگی خط به‌روزرسانی بیرون از حلقه | حلقه بی‌نهایت |
| استفاده از `continue` به‌جای `break` | یک آیتم را رد می‌کند به‌جای خروج |
| انتظار اینکه `for` روی `range` کران بالا را شامل شود | خطای یکی‌زیاد |

## فعالیت‌های کارگاه

۱. **جدول ضرب.** یک عدد بگیرید و جدول ۱ تا ۱۰ آن را با حلقه `for` چاپ کنید. بعد همان خروجی را با حلقه `while` بازنویسی کنید و مقایسه کنید.
۲. **بازی حدس عدد.** یک عدد رمزی بین ۱ تا ۱۰ انتخاب کنید. تا وقتی کاربر درست حدس نزده حلقه کنید، و بعد از هر تلاش بگویید زده بالا یا پایین.
۳. **تکرار تا ورودی معتبر.** یک عدد بخواهید و تا وقتی کاربر واقعاً عددی ننوشته بازو پرسید کنید. این یک حلقه `while` با `try/except` در درونش است که در جلسه ۱۸ رسمی‌اش می‌کنیم.
۴. **ردیابی با دست.** سه حلقه از روی تخته بردارید، جدولی از مقدار متغیر حلقه در هر تکرار بنویسید، بعد اجرا کنید و بررسی کنید.

## تکالیف

- **الگوهای حلقه**: چاپ اعداد زوج، شمارش معکوس تا صفر، و چاپ مثلثی از ستاره‌ها.
- **تمرین ردیابی**: برای چهار حلقه، مقدار همه متغیرها را در هر تکرار به‌صورت جدول نشان دهید.
- **برنامه‌های کوچک**: جمع مربع‌های n عدد اول، محاسبه فاکتوریل، و پیدا کردن نخستین عدد بالای ۱۰۰ که بر ۳ و ۷ بخش‌پذیر است.
- **چالش تبدیل**: سه برنامه از جلسه ۱۲ را با حلقه به‌جای تکرار بازنویسی کنید.

## نکات کلیدی

- `for` وقتی دنباله را می‌دانید، `while` وقتی نمی‌دانید.
- `range(n)` پیش از `n` می‌ایستد. این خطا نیست.
- هر حلقه `while` باید چیزی را تغییر دهد که به سمت پایان برود.
- `break` خارج می‌شود؛ `continue` رد می‌کند. انتخاب اشتباه آسان و بی‌صداست.
- حلقه‌های تودرتو ضرب می‌شوند، پس یک اشتباه کوچک گران تمام می‌شود.
