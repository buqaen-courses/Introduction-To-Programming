# تبدیل دهدهی و باینری: یادگیری ترجمه بین اعداد انسانی و کامپیوتری

## مقدمه: چرا تبدیل کنیم؟

تصور کنید به کشوری سفر می‌کنید که مردم آنجا چیزها را متفاوت می‌شمارند. در یک کشور برای ۱۲ آیتم می‌گویند «دوازده». در کشور دیگر ممکن است بگویند «یک-دو» یا کلمات کاملاً متفاوتی استفاده کنند. به‌عنوان مسافر، باید یاد بگیرید ترجمه کنید!

**دهدهی (پایه ۱۰)** روشی است که انسان‌ها می‌شمارند (۰-۹).
**باینری (پایه ۲)** روشی است که کامپیوترها می‌شمارند (۰-۱).

یادگیری تبدیل بین این دو مثل یادگیری صحبت کردن به دو زبان است.

### نمایش بصری ارزش جایگاه

**دهدهی: عدد ۴٬۲۳۷**
```
Thousands  Hundreds  Tens    Ones
   │          │       │       │
   4          2       3       7
   │          │       │       │
4×1000  +  2×100  + 3×10  + 7×1
   │          │       │       │
4000    +   200   +  30   +  7   = 4,237
```

**باینری: عدد ۱۰۱۰۱۰ (که ۴۲ در دهدهی است)**
```
Position:   5    4    3    2    1    0
Value:     32   16    8    4    2    1
Bit:        1    0    1    0    1    0
            │    │    │    │    │    │
          32×1 + 16×0 + 8×1 + 4×0 + 2×1 + 1×0
            │    │    │    │    │    │
           32  +  0  +  8  +  0  +  2  +  0  = 42
```

## تبدیل دهدهی به باینری

### روش ۱: تفریق (مناسب مبتدی)

این روش شهودی است - مثل پول دادن با سکه‌های ارزش‌های متفاوت.

**سکه‌های توان‌های ۲**
```
Position:   7    6    5    4    3    2    1    0
Value:    128   64   32   16    8    4    2    1
```

**فرآیند گام‌به‌گام:**
۱. بزرگ‌ترین توان ۲ را پیدا کنید که در عددتان جا شود
۲. در آن جایگاه ۱ بگذارید
۳. آن مقدار را از عددتان کم کنید
۴. تا رسیدن به صفر تکرار کنید
۵. جایگاه‌های باقی‌مانده را با صفر پر کنید

### مثال: تبدیل ۴۵ به باینری

```
Step 1: What's the largest power of 2 ≤ 45?
        64 is too big, 32 fits! ✓
        Put 1 in position 5 (32)
        45 - 32 = 13 remaining

        Positions:  7  6  5  4  3  2  1  0
        Values:   128 64 32 16  8  4  2  1
        Bits:       0  0  1  ?  ?  ?  ?  ?

Step 2: What's the largest power of 2 ≤ 13?
        16 is too big, 8 fits! ✓
        Put 1 in position 3 (8)
        13 - 8 = 5 remaining

        Bits:       0  0  1  0  1  ?  ?  ?

Step 3: What's the largest power of 2 ≤ 5?
        8 is too big, 4 fits! ✓
        Put 1 in position 2 (4)
        5 - 4 = 1 remaining

        Bits:       0  0  1  0  1  1  ?  ?

Step 4: What's the largest power of 2 ≤ 1?
        1 fits! ✓
        Put 1 in position 0 (1)
        1 - 1 = 0 (Done!)

        Bits:       0  0  1  0  1  1  0  1

Answer: 45₁₀ = 00101101₂

Check: 32 + 8 + 4 + 1 = 45 ✓
```

### روش ۲: تقسیم بر ۲ (الگوریتم سنتی)

**قاعده:** بر ۲ تقسیم کنید، باقی‌مانده‌ها را نگه دارید، باقی‌مانده‌ها را از پایین به بالا بخوانید.

**مثال: تبدیل ۴۲ به باینری**
```
42 ÷ 2 = 21 remainder 0  ↑  (read these up)
21 ÷ 2 = 10 remainder 1  ↑
10 ÷ 2 = 5  remainder 0  ↑
5  ÷ 2 = 2  remainder 1  ↑
2  ÷ 2 = 1  remainder 0  ↑
1  ÷ 2 = 0  remainder 1  ↑ (start here)

Reading bottom to top: 101010

Answer: 42₁₀ = 101010₂

Check: 32 + 8 + 2 = 42 ✓
```

**چرا کار می‌کند:** هر تقسیم بر ۲ به ما می‌گوید آیا عدد زوج است (باقی‌مانده ۰) یا فرد (باقی‌مانده ۱). این کم‌ارزش‌ترین بیت است. با خارج‌القسمت ادامه می‌دهیم تا صفر شود.

### نمونه‌های بیشتر تبدیل

| دهدهی | باینری | چگونه به دست آمد |
|-------|--------|-------------------|
| ۵ | ۰۰۰۰۰۱۰۱ | ۴ + ۱ |
| ۱۰ | ۰۰۰۰۱۰۱۰ | ۸ + ۲ |
| ۱۳ | ۰۰۰۰۱۱۰۱ | ۸ + ۴ + ۱ |
| ۲۵ | ۰۰۰۱۱۰۰۱ | ۱۶ + ۸ + ۱ |
| ۵۰ | ۰۰۱۱۰۰۱۰ | ۳۲ + ۱۶ + ۲ |
| ۱۰۰ | ۰۱۱۰۰۱۰۰ | ۶۴ + ۳۲ + ۴ |
| ۲۵۵ | ۱۱۱۱۱۱۱۱ | ۱۲۸+۶۴+۳۲+۱۶+۸+۴+۲+۱ |

## تبدیل باینری به دهدهی

### روش استاندارد: جمع ارزش جایگاه‌ها

**فرمول ساده:** جایی که ۱ هست، ارزش آن جایگاه را جمع کنید.

### مثال: تبدیل ۱۰۱۱۰۱ به دهدهی

```
Position:   5    4    3    2    1    0
Bit:        1    0    1    1    0    1
Value:     32   16    8    4    2    1
            │    │    │    │    │    │
          32×1 + 16×0 + 8×1 + 4×1 + 2×0 + 1×1
            │    │    │    │    │    │
           32  +  0  +  8  +  4  +  0  +  1  = 45

Answer: 101101₂ = 45₁₀
```

### روش کوتاه «دو برابر کردن»

این روش عدد باینری را از چپ به راست پردازش می‌کند:

**الگوریتم:**
۱. از صفر شروع کنید
۲. برای هر بیت: نتیجه فعلی را دو برابر کنید، بعد بیت را اضافه کنید
۳. نتیجه نهایی جواب است

**مثال: تبدیل ۱۰۱۱۰۱ به دهدهی**
```
Bits:  1    0    1    1    0    1

Step 1: Start with 0
Step 2: 0 × 2 + 1 = 1
Step 3: 1 × 2 + 0 = 2
Step 4: 2 × 2 + 1 = 5
Step 5: 5 × 2 + 1 = 11
Step 6: 11 × 2 + 0 = 22
Step 7: 22 × 2 + 1 = 45

Answer: 45₁₀
```

**چرا کار می‌کند:** این همان چیزی است که: ((((۱×۲+۰)×۲+۱)×۲+۱)×۲+۰)×۲+۱

## ترفندهای تبدیل سریع

### ترفند ۱: زوج یا فرد؟

به بیت راست‌ترین نگاه کنید:
- با **۰** تمام می‌شود = **زوج**
- با **۱** تمام می‌شود = **فرد**

**مثال‌ها:**
- ۱۰۱۰₂ با ۰ تمام می‌شود → زوج → ۱۰₁۰ ✓
- ۱۱۱۱₂ با ۱ تمام می‌شود → فرد → ۱۵₁۰ ✓

### ترفند ۲: آیا توان ۲ است؟

یک عدد توان ۲ است اگر باینری‌اش دقیقاً **یک ۱** داشته باشد و بقیه صفر:
- ۰۰۰۰۱۰۰۰ = ۸ = ۲۳ ✓
- ۰۰۱۰۰۰۰۰ = ۳۲ = ۲۵ ✓
- ۰۰۰۰۱۱۰۰ = ۱۲ (توان ۲ نیست، دو ۱ دارد) ✗

### ترفند ۳: الگوی جمع باینری

وقتی ۱ را به عدد باینری که همه بیت‌های انتهایی‌اش ۱ هستند اضافه می‌کنید:
```
   0111  (7)
 + 0001  (1)
 ------
   1000  (8)
```

همه ۱های انتهایی به ۰ می‌روند و اولین ۰ به ۱ می‌رود!

## کاربردهای دنیای واقعی

### کاربرد ۱: آدرس‌های IP

آدرس IP `192.168.1.1` در باینری:
```
192 = 11000000
168 = 10101000
1   = 00000001
1   = 00000001

Full: 11000000.10101000.00000001.00000001
```

### کاربرد ۲: مقادیر رنگ

رنگ وب `#FF5733` (نارنجی-قرمز):
```
FF = 11111111 (Red = 255)
57 = 01010111 (Green = 87)
33 = 00110011 (Blue = 51)
```

### کاربرد ۳: مجوزهای فایل

مجوز یونیکس `755`:
```
7 (owner)  = 111 = rwx (read, write, execute)
5 (group)  = 101 = r-x (read, no write, execute)
5 (others) = 101 = r-x (read, no write, execute)
```

## نکات کلیدی

۱. **دو روش اصلی تبدیل:**
   - دهدهی → باینری: تفریق توان‌های ۲ (آسان‌تر) یا تقسیم بر ۲
   - باینری → دهدهی: جمع ارزش جایگاه‌ها یا روش دو برابر کردن

۲. **توان‌های ۲ را حفظ کنید:** همه‌جا در محاسبات ظاهر می‌شوند

۳. **۸ بیت = ۱ بایت:** واحد ذخیره‌سازی بنیادی

۴. **الگوها به تشخیص کمک می‌کنند:**
   - اعداد زوج با ۰ تمام می‌شوند
   - توان‌های ۲ یک ۱ و بقیه صفر دارند
   - ۲۵۵ = ۱۱۱۱۱۱۱۱ (همه بیت‌ها روشن)

۵. **تمرین کردن یعنی تسلط:** با اعداد کوچک شروع کنید، بالا بروید
