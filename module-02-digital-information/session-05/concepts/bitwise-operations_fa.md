# عملیات بیتی: قدرت کار با بیت‌های تکی

## مقدمه: فکر کردن مثل یک کامپیوتر

تصور کنید ۸ کلید چراغ روشنایی دارید، هرکدام با برچسب ۰ تا ۷. به‌جای اینکه با همه آن‌ها یکسان رفتار کنید، می‌خواهید:
- فقط کلید شماره ۳ را روشن کنید
- بررسی کنید کلید شماره ۵ روشن است یا نه
- وضعیت همه کلیدها را برعکس کنید

دقیقاً همین کار را **عملیات بیتی** انجام می‌دهند! این عملیات اجازه می‌دهند بیت‌های تکی، یعنی کوچک‌ترین واحدهای داده در کامپیوتر، را دستکاری کنید.

## شش عملیات بیتی پایه

### ۱. AND (&): هر دو باید روشن باشند

**قاعده:** نتیجه فقط وقتی ۱ است که **هر دو** بیت ۱ باشند.

| A | B | A & B |
|---|---|-------|
| ۰ | ۰ | ۰ |
| ۰ | ۱ | ۰ |
| ۱ | ۰ | ۰ |
| ۱ | ۱ | ۱ |

**مثل این فکر کنید:** دو نفر هر دو باید چیزی را تأیید کنند.

**مثال:**
```
  11001100    (204)
& 10101010    (170)
----------
  10001000    (136)

Only positions where BOTH have 1 stay as 1
```

**کاربرد عملی:** ماسک کردن (پنهان کردن بیت‌هایی که برایتان مهم نیستند)

---

### ۲. OR (|): حداقل یکی روشن

**قاعده:** نتیجه اگر **هر کدام** از بیت‌ها ۱ باشد، ۱ است.

| A | B | A \| B |
|---|---|-------|
| ۰ | ۰ | ۰ |
| ۰ | ۱ | ۱ |
| ۱ | ۰ | ۱ |
| ۱ | ۱ | ۱ |

**مثل این فکر کنید:** هر کدام از دو نفر می‌تواند تأیید کند.

**مثال:**
```
  11001100    (204)
| 10101010    (170)
----------
  11101110    (238)

Any position with at least one 1 stays as 1
```

**کاربرد عملی:** تنظیم پرچم‌ها (روشن کردن بیت‌ها)

---

### ۳. XOR (^): بیت‌های متفاوت

**قاعده:** نتیجه اگر بیت‌ها **متفاوت** باشند، ۱ است.

| A | B | A ^ B |
|---|---|-------|
| ۰ | ۰ | ۰ |
| ۰ | ۱ | ۱ |
| ۱ | ۰ | ۱ |
| ۱ | ۱ | ۰ |

**مثل این فکر کنید:** «آیا این‌ها متفاوت‌اند؟»

**مثال:**
```
  11001100    (204)
^ 10101010    (170)
----------
  01100110    (102)

Positions where bits differ become 1
```

**کاربرد عملی:**
- جابه‌جایی وضعیت بیت‌ها (روشن به خاموش، خاموش به روشن)
- رمزنگاری ساده (XOR با یک کلید)
- پیدا کردن تفاوت بین دو مقدار

---

### ۴. NOT (~): معکوس کردن همه بیت‌ها

**قاعده:** هر ۰ را ۱ و هر ۱ را ۰ کنید.

| A | ~A |
|---|----|
| ۰ | ۱ |
| ۱ | ۰ |

**مثال:**
```
~ 00001111    (15)
----------
  11110000    (240 in 8-bit unsigned)

All bits flipped
```

**نکته:** در برنامه‌نویسی، نتیجه بستگی دارد که عددتان چند بیت باشد (۸-بیتی، ۱۶-بیتی، ۳۲-بیتی و غیره).

---

### ۵. جابه‌جایی چپ (<<): انتقال بیت‌ها به چپ

**قاعده:** همه بیت‌ها را به چپ ببرید، سمت راست را با صفر پر کنید.

**اثر:** هر جابه‌جایی چپ، عدد را در ۲ ضرب می‌کند!

**مثال:**
```
00000101 (5)
<< 1
--------
00001010 (10)  = 5 × 2

00000101 (5)
<< 2
--------
00010100 (20)  = 5 × 4

00000101 (5)
<< 3
--------
00101000 (40)  = 5 × 8
```

**کاربرد عملی:**
- ضرب سریع در توان‌های ۲
- راه‌اندازی ماسک‌های بیتی
- ساختن پرچم

---

### ۶. جابه‌جایی راست (>>): انتقال بیت‌ها به راست

**قاعده:** همه بیت‌ها را به راست ببرید، سمت چپ را با صفر پر کنید (یا بیت علامت برای اعداد امضادار).

**اثر:** هر جابه‌جایی راست، عدد را بر ۲ تقسیم می‌کند!

**مثال (بدون علامت):**
```
00010100 (20)
>> 1
--------
00001010 (10)  = 20 ÷ 2

00010100 (20)
>> 2
--------
00000101 (5)   = 20 ÷ 4
```

**کاربرد عملی:**
- تقسیم سریع بر توان‌های ۲
- استخراج بیت‌های مشخص
- باز کردن بسته داده فشرده

## کاربردهای عملی

### کاربرد ۱: بررسی زوج یا فرد بودن عدد

**ترفند:** به راست‌ترین بیت (بیت ۰) نگاه کنید
- ۰ = زوج
- ۱ = فرد

```python
# Check if number is even
def is_even(number):
    return (number & 1) == 0

# Check if number is odd
def is_odd(number):
    return (number & 1) == 1

# Examples:
is_even(4)   # 4 & 1 = 0, returns True ✓
is_even(7)   # 7 & 1 = 1, returns False ✓
is_odd(7)    # 7 & 1 = 1, returns True ✓
```

**چطور کار می‌کند:**
```
4 = 100
1 = 001
& = 000 = 0 → زوج!

7 = 111
1 = 001
& = 001 = 1 → فرد!
```

---

### کاربرد ۲: روشن کردن یک بیت مشخص

**هدف:** روشن کردن یک بیت مشخص (موقعیت n)

```python
def set_bit(number, position):
    return number | (1 << position)

# Examples:
set_bit(0b0000, 2)   # Set bit 2
# 1 << 2 = 0b0100
# 0b0000 | 0b0100 = 0b0100 = 4

set_bit(0b1000, 0)   # Set bit 0
# 1 << 0 = 0b0001
# 0b1000 | 0b0001 = 0b1001 = 9
```

---

### کاربرد ۳: خاموش کردن یک بیت مشخص

**هدف:** خاموش کردن یک بیت مشخص (موقعیت n)

```python
def clear_bit(number, position):
    return number & ~(1 << position)

# Examples:
clear_bit(0b1111, 2)  # Clear bit 2
# 1 << 2 = 0b0100
# ~0b0100 = 0b1011 (in 4 bits)
# 0b1111 & 0b1011 = 0b1011 = 11
```

---

### کاربرد ۴: جابه‌جایی وضعیت یک بیت

**هدف:** برعکس کردن یک بیت (روشن به خاموش یا خاموش به روشن)

```python
def toggle_bit(number, position):
    return number ^ (1 << position)

# Examples:
toggle_bit(0b1010, 0)  # Toggle bit 0
# 0b1010 ^ 0b0001 = 0b1011 = 11
# Was 0, now 1

toggle_bit(0b1011, 0)  # Toggle bit 0 again
# 0b1011 ^ 0b0001 = 0b1010 = 10
# Was 1, now 0
```

---

### کاربرد ۵: بررسی تنظیم بودن یک بیت

**هدف:** آیا یک بیت مشخص روشن است؟

```python
def is_bit_set(number, position):
    return (number & (1 << position)) != 0

# Examples:
is_bit_set(0b1010, 1)  # Check bit 1
# 0b1010 & 0b0010 = 0b0010 != 0 → True

is_bit_set(0b1010, 0)  # Check bit 0
# 0b1010 & 0b0001 = 0b0000 == 0 → False
```

### کاربرد ۶: مجوزهای فایل (سبک یونیکس)

در سیستم‌های یونیکس/لینوکس، مجوزهای فایل از ۳ بیت برای هر ۳ گروه استفاده می‌کنند:

```
Permissions format: rwx rwx rwx
                    │   │   │
                  owner group others

r = read    (4) = 100
w = write   (2) = 010
x = execute (1) = 001
```

**مقادیر مجوز رایج:**
```
7 = 111 = rwx (خواندن، نوشتن، اجرا)
6 = 110 = rw- (خواندن، نوشتن، بدون اجرا)
5 = 101 = r-x (خواندن، بدون نوشتن، اجرا)
4 = 100 = r-- (فقط خواندن)
0 = 000 = --- (بدون مجوز)

Permission 755 = rwxr-xr-x
  Owner:  7 = 111 = rwx
  Group:  5 = 101 = r-x
  Others: 5 = 101 = r-x
```

**بررسی مجوز با عملیات بیتی:**
```python
def can_read(permissions):
    return (permissions & 4) != 0  # Check read bit

def can_write(permissions):
    return (permissions & 2) != 0  # Check write bit

def can_execute(permissions):
    return (permissions & 1) != 0  # Check execute bit

# Example: Check if owner can write
owner_perms = 7  # rwx
if can_write(owner_perms):
    print("Can write!")
```

### کاربرد ۷: ذخیره چند پرچم boolean

به‌جای استفاده از چند متغیر boolean، آن‌ها را در یک عدد صحیح بسته‌بندی کنید:

```python
# Define flags
IS_VISIBLE = 1 << 0    # Bit 0
IS_ENABLED = 1 << 1    # Bit 1
IS_HOVERED = 1 << 2    # Bit 2
IS_CLICKED = 1 << 3    # Bit 3

# Set multiple flags
button_state = IS_VISIBLE | IS_ENABLED
# 0001 | 0010 = 0011

# Check if specific flag is set
if button_state & IS_VISIBLE:
    print("Button is visible")

# Add a flag
button_state |= IS_HOVERED
# 0011 | 0100 = 0111

# Remove a flag
button_state &= ~IS_ENABLED
# 0111 & 1101 = 0101
```

**صرفه‌جویی در حافظه:**
- ۴ boolean جدا: ۴ بایت (معمولاً)
- ۱ عدد صحیح با ۴ پرچم: ۴ بایت
- ولی می‌توانید ۳۲ پرچم را در یک عدد ۳۲-بیتی بسته‌بندی کنید!

## ماسک‌های بیتی رایج

### ماسک چیست؟

**ماسک** الگویی از بیت‌هاست که برای انتخاب یا تغییر بیت‌های مشخص استفاده می‌شود.

### ماسک‌های رایج

| هدف | ماسک (۸-بیتی) | توضیح |
|-----|--------------|-------|
| ۴ بیت پایین | 00001111 | فقط بیت‌های ۰ تا ۳ را نگه دار |
| ۴ بیت بالا | 11110000 | فقط بیت‌های ۴ تا ۷ را نگه دار |
| بیت‌های زوج | 01010101 | بیت‌های ۰، ۲، ۴، ۶ را نگه دار |
| بیت‌های فرد | 10101010 | بیت‌های ۱، ۳، ۵، ۷ را نگه دار |
| یک بیت | 00001000 | فقط بیت ۳ را نگه دار |

### استفاده از ماسک‌ها

```python
# Extract lower 4 bits
value = 0b10110101
lower_4 = value & 0b00001111
# Result: 0b00000101 = 5

# Extract upper 4 bits
upper_4 = (value & 0b11110000) >> 4
# Result: 0b00001011 = 11
```

## نکات کلیدی

۱. **AND (&)** بیت‌هایی را نگه می‌دارد که هر دو ۱ هستند - برای ماسک کردن
۲. **OR (|)** بیت‌هایی را نگه می‌دارد که هر کدام ۱ هستند - برای تنظیم
۳. **XOR (^)** بیت‌هایی را نگه می‌دارد که متفاوت‌اند - برای جابه‌جایی وضعیت
۴. **NOT (~)** همه بیت‌ها را معکوس می‌کند - برای وارونه کردن
۵. **جابه‌جایی (<<، >>)** بیت‌ها را چپ/راست می‌برد - برای ضرب/تقسیم بر ۲
۶. **عملیات بیتی سریع است** - در سطح سخت‌افزار انجام می‌شود

## به یاد داشته باشید

| عملیات | نماد | وقتی می‌خواهید... |
|--------|------|-------------------|
| AND | & | بررسی کنید هر دو بیت تنظیم‌اند، بیت‌ها را ماسک کنید |
| OR | \| | بیت‌ها را ۱ کنید |
| XOR | ^ | جابه‌جایی وضعیت بیت‌ها، پیدا کردن تفاوت‌ها |
| NOT | ~ | معکوس کردن همه بیت‌ها |
| جابه‌جایی چپ | << | ضرب در ۲، انتقال بیت‌ها به چپ |
| جابه‌جایی راست | >> | تقسیم بر ۲، انتقال بیت‌ها به راست |
