# جلسه ۱۶: مجموعه‌ها، فهرست، تاپل، دیکشنری و set

## مرور جلسه

یک رشته فقط یک تکه متن را نگه می‌دارد. برنامه‌های واقعی هم‌زمان *چند* چیز را نگه می‌دارند، و نوعی که برای آن‌ها انتخاب می‌کنید تغییر می‌دهد کد شما چطور کار کند و چقدر سریع باشد. این جلسه چهار مجموعه اصلی پایتون، یعنی فهرست، دیکشنری، تاپل و مجموعه، را معرفی می‌کند، هرکدام به چه کاری خوب است، و چطور انتخاب کنید. همچنین list comprehension را معرفی می‌کند که جای بیشتر حلقه‌هایی را می‌گیرد که جلسه قبل نوشتید.

## اهداف یادگیری کلیدی

در پایان این جلسه می‌توانید:

- **توضیح دهید** هر یک از چهار نوع مجموعه چه زمانی استفاده می‌شود
- **بسازید**، **اندیس بگذارید** و **تغییر دهید** فهرست و دیکشنری
- **پیمایش کنید** مجموعه‌ها با حلقه `for`
- **بنویسید** list comprehension و dict comprehension
- **به‌کار ببرید** تاپل برای گروه‌های ثابت و set برای یکتایی
- **انتخاب کنید** یک مجموعه بر اساس الگوی دسترسی‌ای که نیاز دارید

## انتخاب مجموعه

این تصمیمی است که از همه مهم‌تر است:

```
    ┌──────────────┬────────────────────┬───────────┬──────────────┐
    │  TYPE        │  ORDERED?          │ MUTABLE?  │  LOOKUP BY   │
    ├──────────────┼────────────────────┼───────────┼──────────────┤
    │  list        │  yes               │ yes       │  position    │
    │  tuple       │  yes               │ no        │  position    │
    │  dict        │  yes (insertion)   │ yes       │  key         │
    │  set         │  no                │ yes       │  membership  │
    └──────────────┴────────────────────┴───────────┴──────────────┘
```

به زبان ساده: **فهرست** ردیفی از آیتم‌های مرتب و قابل تغییر است. **تاپل** همان است ولی قفل شده. **دیکشنری** جدول جست‌وجویی با کلید اسمی است. **مجموعه** کیسه‌ای از مقادیر یکتاست که ترتیبش اهمیت ندارد.

## فهرست: ابزار اصلی

```python
fruits = ["apple", "banana", "cherry"]

fruits[0]          # "apple"
fruits[-1]         # "cherry"
fruits[1:3]        # ["banana", "cherry"]
len(fruits)        # 3

fruits.append("date")          # اضافه کردن به انتها
fruits.insert(0, "fig")        # اضافه کردن به ابتدا
fruits.remove("banana")        # حذف بر اساس مقدار
fruits.pop()                   # حذف آخرین آیتم و بازگرداندنش
fruits.sort()                  # مرتب‌سازی درجا
```

به عدم تقارن دقت کنید: `sort()` خود فهرست را تغییر می‌دهد و `None` برمی‌گرداند. `sorted(fruits)` یک فهرست مرتب **تازه** برمی‌گرداند و اصل را دست‌نخورده می‌گذارد.

## دیکشنری: از نام به مقدار

وقتی داده‌های شما برچسب دارند نه موقعیت، از دیکشنری استفاده کنید:

```python
student = {"name": "Sara", "age": 21, "gpa": 3.8}

student["name"]              # "Sara"
student["major"] = "CS"      # افزودن کلید
student.get("major", "N/A")  # دسترسی امن، بدون KeyError
"age" in student             # True

for key, value in student.items():
    print(key, value)
```

`student["major"]` اگر کلید موجود نباشد `KeyError` می‌دهد. `.get()` با مقدار پیش‌فرض چنین نمی‌کند. این همان عادت دفاعی است که در جلسه ۱۸ با exception رسمی‌اش می‌کنید.

## تاپل و مجموعه

**تاپل** تغییرناپذیر است، یعنی استفاده از آن به‌عنوان کلید دیکشنری امن است و به‌طور تصادفی تغییر نمی‌کند:

```python
point = (3, 5)
x, y = point              # باز کردن بسته
colors = ("red", "green", "blue")   # این تغییر نمی‌کند
```

**مجموعه** فقط مقادیر یکتا نگه می‌دارد و به پرسش «آیا این در آن هست؟» بی‌درنگ پاسخ می‌دهد:

```python
visitors = ["Ali", "Sara", "Ali", "Reza"]
unique = set(visitors)    # {"Ali", "Sara", "Reza"}  <- علی یکی شد
"Ali" in unique           # True، حتی برای مجموعه‌های بسیار بزرگ سریع است

a = {1, 2, 3}
b = {2, 3, 4}
a & b     # {2, 3}        اشتراک
a | b     # {1, 2, 3, 4}  اجتماع
a - b     # {1}           تفاضل
```

مجموعه‌ها ترتیب را با یکتایی و سرعت جست‌وجو معاوضه می‌کنند. تمام معامله همین است.

## Comprehension

یک comprehension مجموعه‌ای را در یک عبارت می‌سازد. کوتاه‌تر است و معمولاً از حلقه معادل سریع‌تر:

```python
# حلقه‌ای که می‌نوشتید
squares = []
for n in range(10):
    squares.append(n * n)

# comprehension
squares = [n * n for n in range(10)]

# با شرط
evens = [n for n in range(20) if n % 2 == 0]

# dict comprehension
lengths = {word: len(word) for word in ["cat", "dog", "horse"]}
```

## مفاهیم اصلی

- **فهرست**: مرتب، تغییرپذیر، با اندیس بر اساس موقعیت
- **تاپل**: مرتب، تغییرناپذیر؛ قابل استفاده به‌عنوان کلید دیکشنری
- **دیکشنری**: نگاشت کلید-مقدار با جست‌وجوی O(1)
- **مجموعه**: عناصر یکتا، بدون ترتیب، تست عضویت سریع
- **`sort()` در برابر `sorted()`**: اولی تغییر می‌دهد، دومی شیء تازه برمی‌گرداند
- **`.get()` با پیش‌فرض** از `KeyError` جلوگیری می‌کند
- **Comprehension**: ساخت مجموعه از یک iterable در یک عبارت
- **باز کردن بسته**: `x, y = point` بهتر از `point[0]`، `point[1]` خوانده می‌شود

## اشتباهات رایج مبتدی

| اشتباه | نتیجه |
|--------|-------|
| `x = mylist.sort()` | `x` مقدار `None` می‌گیرد. از `x = sorted(mylist)` استفاده کنید |
| `d["key"]` وقتی کلید ممکن است موجود نباشد | `KeyError`. از `.get()` یا بررسی `in` استفاده کنید |
| تغییر فهرست هنگام پیمایش روی آن | آیتم‌های جاافتاده یا تکراری. روی یک کپی پیمایش کنید |
| انتظار حفظ ترتیب در مجموعه | ترتیب را حفظ نمی‌کند. اگر ترتیب مهم است فهرست استفاده کنید |
| `tuple.append()` | `AttributeError`. تاپل‌ها تغییر نمی‌کنند |
| حلقه `for` تودرتو به‌جای comprehension | کار می‌کند ولی پرحرف است. comprehension خواناتر است |

## فعالیت‌های کارگاه

۱. **فهرست خرید.** فهرستی از اقلام بسازید، به کاربر اجازه دهید آیتم اضافه و حذف کند، بعد کل فهرست را مرتب چاپ کنید.
۲. **دفتر تلفن.** دیکشنری نام به شماره بسازید. سه مخاطب اضافه کنید، یکی را با نام پیدا کنید، و حالت پیدا نشدن نام را هم مدیریت کنید.
۳. **کلمات یکتا.** یک جمله بگیرید، به کلمات بشکنید، و با مجموعه گزارش دهید چند کلمه متفاوت دارد. آن را با شمارش خام مقایسه کنید.
۴. **بررسی عملیات مجموعه.** با دو فهرست شناسه دانش‌آموز، چاپ کنید چه کسانی در هر دو هستند، چه کسانی فقط در اولی هستند، و چه کسانی در هیچ‌کدام نیستند.

## تکالیف

- **تمرین فهرست**: فهرست‌های کوچک بسازید و `insert`، `remove`، `pop`، `sort`، برش و پیمایش را تمرین کنید.
- **کارهای دیکشنری**: نگاشت کشور به پایتخت، بعد پنج مورد را پیدا کنید. برای کلید ناشناخته یک `.get()` با مقدار پیش‌فرض اضافه کنید.
- **عضویت**: بررسی کنید یک آیتم در فهرست، مجموعه و دیکشنری هست یا نه. با یک مجموعه بزرگ زمان هرکدام را بگیرید و تفاوت را توضیح دهید.
- **تمرین comprehension**: پنج حلقه از جلسه ۱۴ را به comprehension تبدیل کنید. اگر موردی تمیز تبدیل نشد، بگویید چرا.

## نکات کلیدی

- مجموعه را بر اساس اینکه چطور *دنبال چیزی می‌گردید* انتخاب کنید، نه بر اساس اینکه چه چیزی در آن نگه می‌دارید.
- `sort()` تغییر می‌دهد؛ `sorted()` شیء تازه برمی‌گرداند.
- `.get()` با پیش‌فرض، خواندن امن از دیکشنری است.
- تاپل برای چیزهایی است که نباید تغییر کنند؛ مجموعه برای یکتایی.
- Comprehension بیشتر حلقه‌های ساخت مجموعه را جایگزین می‌کند.
