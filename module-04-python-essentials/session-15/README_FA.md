# جلسه ۱۵: کار با رشته‌ها

## مرور جلسه

رشته دنباله‌ای از کاراکترهاست، و تقریباً هر چیزی که کاربر تایپ می‌کند به‌صورت رشته می‌رسد. این جلسه متن را داده‌ای می‌بیند که می‌شود اندیس گذاری، برش داد، جست‌وجو کرد و تبدیلش کرد. همچنین f-string را معرفی می‌کند که روش مدرن ساخت خروجی است، و الگوهای پردازش متن، یعنی تقسیم کردن، به هم چسباندن و پاک‌سازی، که یک رشته به‌هم‌ریخته را به داده‌ای ساخت‌یافته تبدیل می‌کنند که بتوانید رویش کار کنید.

## اهداف یادگیری کلیدی

در پایان این جلسه می‌توانید:

- **اندیس بگذارید** و **برش بگیرید** تا کاراکترها و زیررشته‌ها را استخراج کنید
- **به‌کار ببرید** متدهای اصلی رشته برای جست‌وجو و تبدیل
- **قالب‌بندی کنید** خروجی با f-string، شامل اعداد و تراز
- **تقسیم و به‌هم بچسبانید** متن برای تبدیل بین رشته و فهرست
- **پاک‌سازی کنید** ورودی کاربر با `strip()`، `lower()` و هم‌نوعانشان
- **بسازید** یک برنامه کوچک تحلیل متن

## رشته‌ها دنباله‌اند

رشته یک دنباله است، پس مثل فهرستی از کاراکترها رفتار می‌کند که نمی‌توانید درجا تغییرش دهید:

```python
word = "Python"

print(word[0])      # P
print(word[-1])     # n
print(word[1:4])    # yth      (شروع شامل، پایان غیرشامل)
print(word[::2])    # Pto      (گام ۲)
print(len(word))    # 6
```

قاعده `start:end` را همین حالا حفظ کنید، چون در جلسه ۱۶ برای فهرست‌ها هم کار می‌کند: شروع شامل است، پایان شامل نیست.

## متدهایی که واقعاً استفاده خواهید کرد

```
    CLEANING                  FINDING                 TRANSFORMING
    --------                  -------                 ------------
    .strip()   trim spaces    .find(x)    position    .upper()   to upper
    .lstrip()  trim left      .index(x)   position    .lower()   to lower
    .rstrip()  trim right     x in s      yes/no      .replace() swap text
    .split()   cut to list    s.startswith()
    .splitlines() by lines    s.endswith()
```

وقتی چیزی پیدا نشود، `.find()` مقدار `-1` برمی‌گرداند. `.index()` به‌جای آن خطا می‌دهد. در کد مبتدی که نبودن یک زیررشته چیز عادی است، معمولاً `in` یا `.find()` همان چیزی است که می‌خواهید.

## f-string: عبارت را داخل بگذارید

چسباندن با `+` کار می‌کند ولی زشت می‌شود:

```python
# روش قدیمی
name = "Sara"
print("Hello " + name + ", you are " + str(25) + " years old")

# روش مدرن
print(f"Hello {name}, you are {25} years old")
```

می‌توانید عدد را هم مستقیم داخل آکولاد قالب‌بندی کنید:

```python
price = 1234.5678
print(f"{price:.2f}")        # 1234.57    دو رقم اعشار
print(f"{price:,.2f}")       # 1,234.57   با جداکننده هزارگان
print(f"{42:5d}")            #    42      راست‌چین، عرض ۵
print(f"{42:<5}|")           # 42   |     چپ‌چین
print(f"{42:^7}|")           #   42   |   وسط‌چین
```

این جایگزین `str.format()` و قالب‌بندی با `%` برای هر کد جدیدی است که می‌نویسید.

## split و join

دو متدی که بین دنیای رشته و دنیای فهرست تبدیل می‌کنند:

```python
words = "the quick brown fox".split()
# ['the', 'quick', 'brown', 'fox']

line = ",".join(words)
# 'the,quick,brown,fox'

lines = """first
second
third""".splitlines()
# ['first', 'second', 'third']
```

`split()` بدون آرگومان روی هر فاصله‌ای می‌شکند و خالی‌ها را حذف می‌کند. `split(",")` روی کامای مشخص می‌شکند. این جفت را به خاطر بسپارید، کاربردی‌ترین الگوی پردازش متن در این زبان است.

## مفاهیم اصلی

- **رشته‌ها دنباله‌های تغییرناپذیرند**؛ برش یک رشته تازه برمی‌گرداند
- **`s[start:end]`** با پایان غیرشامل
- **`.strip()`، `.lower()`، `.upper()`** برای پاک‌سازی ورودی کاربر
- **`.find()` مقدار `-1` می‌دهد**؛ `.index()` خطا می‌دهد؛ `in` مقدار boolean می‌دهد
- **f-string** با الگوی `f"{value:.2f}"` برای قالب‌بندی درجا
- **`.split()` و `.join()`** پل بین متن و داده ساخت‌یافته‌اند
- **`enumerate()` روی خروجی `split()`** الگوی استاندارد پردازش خط‌به‌خط است

## اشتباهات رایج مبتدی

| اشتباه | نتیجه |
|--------|-------|
| `word[0] = "X"` | `TypeError`. رشته‌ها را نمی‌شود تغییر داد |
| استفاده مستقیم از نتیجه `.find()` در `if` | `-1` درست‌سنج است، پس بررسی همیشه قبول می‌شود. باید `!= -1` را تست کنید |
| ترکیب `str` و `int` با `+` | `TypeError`. تبدیل صریح لازم است |
| استفاده از قالب‌بندی `%` وقتی رشته `%` دارد | رفتار گیج‌کننده. f-string ترجیح دارد |
| `.split(" ")` روی ورودی با فاصله دوتایی | رشته‌های خالی در نتیجه. از `.split()` استفاده کنید |
| فرض اینکه `.splitlines()` با `\r\n` کار نمی‌کند | کار می‌کند، ولی `.split("\n")` کار نمی‌کند |

## فعالیت‌های کارگاه

۱. **قالب‌بندی نام.** نام و نام خانوادگی بگیرید. نام را با حروف بزرگ، کوچک، عنوان‌بندی‌شده و به شکل حرف اول (`Ali R.`) چاپ کنید.
۲. **شمارش کلمات.** با `.split()` کلمات یک جمله را بشمارید، بعد با `len()` کاراکترها را. با یک حلقه بلندترین کلمه را پیدا کنید.
۳. **شمارش کاراکتر.** یک کاراکتر بگیرید و بشمارید در یک جمله چند بار آمده است.
۴. **گزارش مصوتات.** برای یک جمله داده‌شده، تعداد هر مصوت (`a e i o u`) را چاپ کنید. اول `.lower()` کنید تا فقط یک حالت را مدیریت کنید.

## تکالیف

- **کارهای رشته‌ای**: بررسی اینکه رشته با کاراکترهای خاصی شروع یا تمام می‌شود، و نوشتن تابع ساده‌ای برای سانسور کردن که یک کلمه را با `***` جایگزین کند.
- **تمرین برش**: با ده رشته، سه کاراکتر اول، سه کاراکتر آخر، هر کاراکتر یک‌درمیان، و رشته برعکس را استخراج کنید.
- **چالش کوچک**: یک رشته را برعکس کنید. یک بار با برش و یک بار با حلقه، بعد بگویید کدام را ترجیح می‌دهید و چرا.
- **قالب‌بند**: با f-string و تراز راست برای نام کالاها و قیمت با دو رقم اعشار، برنامه‌ای بنویسید که رسید چاپ کند.

## نکات کلیدی

- رشته‌ها دنباله‌اند، پس اندیس و برش مثل فهرست‌ها کار می‌کنند.
- رشته‌ها تغییرناپذیرند؛ هر متد رشته تازه‌ای برمی‌گرداند.
- `.find()` مقدار `-1` می‌دهد که درست‌سنج است. نتیجه را تست کنید، به آن اعتماد نکنید.
- f-string روشن‌ترین راه ساخت خروجی است.
- `.split()` و `.join()` پل میان متن و داده ساخت‌یافته‌اند.
