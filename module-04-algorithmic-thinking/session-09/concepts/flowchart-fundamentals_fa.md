# مبانی فلوچارت: طراحی بصری الگوریتم

## فلوچارت چیست؟

فلوچارت نمایش بصری یک الگوریتم با استفاده از نمادهای استاندارد است که با پیکان به هم وصل شده‌اند. جریان اجرا را از ابتدا تا انتها نشان می‌دهد و درک منطق را در یک نگاه آسان می‌کند.

### چرا از فلوچارت استفاده کنیم؟

- **وضوح بصری**: ساختار الگوریتم را بی‌درنگ می‌بینید
- **دنبال کردن آسان**: برای ردیابی اجرا، پیکان‌ها را دنبال کنید
- **تشخیص سریع خطا**: نمایش بصری، ایرادهای منطقی را آشکار می‌کند
- **زبان جهانی**: نمادها در سراسر جهان شناخته شده‌اند
- **ابزار برنامه‌ریزی**: قبل از نوشتن کد طراحی کنید

---

## نمادهای فلوچارت

| نماد | نام | کاربرد |
|------|-----|--------|
| ⬭ | بیضی (پایان‌دهنده) | نقاط شروع و پایان |
| ⬜ | مستطیل (پردازش) | کنش‌ها، محاسبات، انتساب‌ها |
| 🔷 | لوزی (تصمیم) | پرسش‌های بله/خیر، شرط‌ها |
| 🗄️ | متوازی‌الاضلاع (ورودی/خروجی) | خواندن ورودی یا نمایش خروجی |
| ➡️ | پیکان (خط جریان) | جهت اجرا |
| ○ | دایره (رابط) | اتصال به بخش دیگری از فلوچارت |

## الگوریتم ۱: جمع کردن فهرستی از اعداد

### مسئله
با داشتن فهرستی از اعداد، مجموع آن‌ها را حساب کنید.

### تفکر گام‌به‌گام
۱. برنامه را شروع کنید
۲. فهرست اعداد را بگیرید
۳. از sum = 0 شروع کنید (هنوز چیزی اضافه نکرده‌ایم)
۴. هر عدد را یکی‌یکی نگاه کنید
۵. هر عدد را به مجموع جاری اضافه کنید
۶. وقتی همه اعداد پردازش شدند، نتیجه را نمایش دهید
۷. برنامه را پایان دهید

### شبه‌کد
```
ALGORITHM SumNumbers
    // Calculate sum of a list of numbers

    DECLARE numbers AS ARRAY OF INTEGER
    DECLARE sum, i AS INTEGER

    sum ← 0

    FOR each number IN numbers DO
        sum ← sum + number
    END FOR

    WRITE "Sum is: " + sum
END ALGORITHM
```

    // Find the largest number in a list

    DECLARE numbers AS ARRAY OF INTEGER
    DECLARE max, i AS INTEGER

            max ← numbers[i]  // Found a bigger one!

## الگوریتم ۴: مرتب‌سازی ساده (مرتب‌سازی حبابی)

### مسئله
با داشتن فهرستی از اعداد، آن‌ها را از کوچک‌ترین به بزرگ‌ترین مرتب کنید.

### ایده
اعداد مجاور را مقایسه کنید. اگر به ترتیب درست نبودند، جابه‌جایشان کنید. تا وقتی دیگر هیچ جابه‌جایی لازم نبود تکرار کنید.

### تفکر گام‌به‌گام
۱. برنامه را شروع کنید
۲. فهرست اعداد را بگیرید
۳. هر جفت از اعداد مجاور را نگاه کنید
۴. اگر جفتی خارج از ترتیب بود (اولی بزرگ‌تر)، جابه‌جایشان کنید
۵. فرآیند را تا وقتی در یک دور کامل جابه‌جایی رخ ندهد تکرار کنید
۶. فهرست حالا مرتب است
۷. فهرست مرتب‌شده را نمایش دهید
۸. برنامه را پایان دهید

### شبه‌کد
```
ALGORITHM SimpleSort
    // Sort numbers from smallest to largest

    DECLARE numbers AS ARRAY OF INTEGER
    DECLARE i, temp AS INTEGER
    DECLARE swapped AS BOOLEAN
    DECLARE n AS INTEGER

    n ← LENGTH(numbers)
    swapped ← TRUE

    WHILE swapped = TRUE DO
        swapped ← FALSE

        FOR i FROM 0 TO n-2 DO
            IF numbers[i] > numbers[i+1] THEN
                // Swap the two numbers
                temp ← numbers[i]
                numbers[i] ← numbers[i+1]
                numbers[i+1] ← temp
                swapped ← TRUE
            END IF
        END FOR
    END WHILE

    WRITE "Sorted list: " + numbers
END ALGORITHM
```

## بهترین روش‌های فلوچارت

### ۱. ساده نگه دارید
- یک فلوچارت برای هر الگوریتم
- برچسب‌های واضح و ساده
- از شلوغی پرهیز کنید

### ۲. نمادهای استاندارد
- از نمادهای درست به‌طور یکدست استفاده کنید
- شکل جدید نسازید
- قرارداد را رعایت کنید

### ۳. جهت جریان
- معمولاً از بالا به پایین
- چپ به راست برای شاخه‌ها
- جهت پیکان‌ها واضح باشد

### ۴. لوزی‌های تصمیم
- همیشه دو خروج (بله/خیر، درست/نادرست)
- خروجی‌ها را واضح برچسب بزنید
- فقط یک پرسش در هر لوزی

### ۵. تست فلوچارت خود
- با داده نمونه ردیابی کنید
- همه مسیرها را بررسی کنید (شاخه‌های بله و خیر)
- مطمئن شوید خروجی درست است

## تمرین‌ها

### تمرین ۱: شمردن اعداد
فلوچارتی بسازید که تعداد اعداد یک فهرست را بشمارد.

**راهنما**: مثل جمع، ولی به‌جای اضافه کردن، یک شمارنده را افزایش دهید.

### تمرین ۲: یافتن میانگین
فلوچارتی بسازید که میانگین فهرستی از اعداد را حساب کند.

**راهنما**: اول اعداد را جمع کنید، بعد بر تعداد تقسیم کنید.

### تمرین ۳: بررسی وجود یک عدد
فلوچارتی بسازید که بررسی کند آیا عدد مشخصی در فهرست هست یا نه.

**راهنما**: اگر پیدایش کردید زودتر متوقف شوید (به این جست‌وجوی خطی می‌گویند).

## از فلوچارت تا کد

### فلوچارت ← شبه‌کد ← پایتون

**گام فلوچارت**: مستطیل «Set sum = 0»

**شبه‌کد**: `sum ← 0`

**پایتون**: `sum = 0`

**گام فلوچارت**: لوزی «Is number > max?»

**شبه‌کد**:
```
IF number > max THEN
    max ← number
END IF
```

**پایتون**:
```python
if number > max:
    max = number
```

## خلاصه

### نکات کلیدی

۱. **فلوچارت الگوریتم بصری است**: تصاویری که منطق برنامه را نشان می‌دهند
۲. **نمادهای استاندارد**: بیضی، مستطیل، لوزی، متوازی‌الاضلاع
۳. **سه الگوی پایه**:
   - **دنباله**: گام‌ها به ترتیب (مستطیل پس از مستطیل)
   - **تصمیم**: شاخه‌های بله/خیر (لوزی با دو خروج)
   - **حلقه**: تکرار گام‌ها (پیکان به گام قبلی برمی‌گردد)
۴. **همیشه ردیابی کنید**: قبل از کدنویسی با داده نمونه تست کنید
۵. **فلوچارت ← شبه‌کد ← کد**: یک فرآیند طراحی سه‌مرحله‌ای
