# جلسه ۱۷: توابع، بلوک‌های قابل استفاده مجدد کد

## مرور جلسه

حالا همه قطعه‌های یک برنامه را دارید: متغیر، شرط، حلقه، مجموعه. چیزی که ندارید راهی است برای نام‌گذاری یک رفتار و استفاده مجدد از آن. توابع همان سازوکارند. این جلسه تعریف تابع، پاس دادن پارامتر، بازگرداندن مقدار و قواعد دامنه که تعیین می‌کند یک متغیر کجا زندگی می‌کند را پوشش می‌دهد. همچنین عادتی را معرفی می‌کند که اسکریپت‌های کارآمد را از کد قابل نگهداری جدا می‌کند: دادن یک کار واحد به هر تابع.

## اهداف یادگیری کلیدی

در پایان این جلسه می‌توانید:

- **تعریف کنید** و **صدا بزنید** تابع با `def`
- **پاس دهید** پارامتر، هم موقعیتی و هم کلیدی
- **برگردانید** مقدار و تفاوت `return` با `print` را تشخیص دهید
- **توضیح دهید** دامنه محلی در برابر سراسری
- **بنویسید** docstring برای هر تابعی که می‌سازید
- **بازآرایی کنید** یک اسکریپت بلند را به توابع نام‌دار

## تعریف و فراخوانی

```python
def greet(name):
    return f"Hello, {name}!"

message = greet("Sara")     # فراخوانی
print(message)              # Hello, Sara!
```

تابع با `def` تعریف می‌شود، بعد با نوشتن نامش و پرانتز صدا زده می‌شود. آن `name` در تعریف یک **پارامتر** است؛ و `"Sara"` در محل فراخوانی یک **آرگومان**.

## return در برابر print

این تمایز تقریباً برای همه یک بار اتفاق می‌افتد:

```python
def add_print(a, b):
    print(a + b)            # چاپ می‌کند، None برمی‌گرداند

result = add_print(2, 3)
print(result)               # None
```

```python
def add_return(a, b):
    return a + b            # مقدار را پس می‌دهد

result = add_return(2, 3)
print(result)               # 5
```

قاعده: `print` چیزی را برای انسان به صفحه می‌فرستد. `return` مقداری را به کدی که شما را صدا زده پس می‌دهد. تابعی که چیزی حساب می‌کند باید آن را `return` کند. `return` هم‌زمان تابع را هم می‌بندد.

## دامنه: متغیرها کجا زندگی می‌کنند

متغیری که داخل یک تابع ساخته می‌شود محلی است و با پایان تابع از بین می‌رود:

```python
count = 0

def increment():
    count = count + 1        # UnboundLocalError!
```

پایتون `count` را در سمت چپ انتساب می‌بیند و کل تابع را محلی فرض می‌کند، بعد مقداری یافت نمی‌کند که به آن نسبت داده شده باشد. قاعده عملی: **مقدارها را داخل بدهید، مقدارها را برگردانید**. سراغ `global` نروید.

```python
def increment(n):
    return n + 1

count = increment(count)
```

## مقادیر پیش‌فرض و پارامترهای منعطف

```python
def greet(name, greeting="Hello", punctuation="!"):
    return f"{greeting}, {name}{punctuation}"

greet("Sara")                        # Hello, Sara!
greet("Sara", "Hi")                  # Hi, Sara!
greet("Sara", punctuation="?")       # Hello, Sara?
greet(greeting="Welcome", name="Ali") # Welcome, Ali!
```

دقت کنید پارامترهای دارای مقدار پیش‌فرض باید *بعد* از آن‌های بدون مقدار بیایند. و به فراخوانی آخر دقت کنید: آرگومان‌های کلیدی می‌توانند به هر ترتیبی بیایند.

```python
def total(*args):        # هر تعداد آرگومان موقعیتی
    return sum(args)

def describe(**kwargs):  # هر تعداد آرگومان کلیدی
    return kwargs

def strict(a, b, *args, **kwargs):  # هر دو
    ...
```

## هر تابع، یک کار

تابعی که یک کار انجام می‌دهد آسان نام‌گذاری، تست و استفاده مجدد می‌شود. تابعی که ورودی می‌خواند، اعتبارسنجی می‌کند، حساب می‌کند، قالب‌بندی می‌کند و چاپ می‌کند هیچ‌کدام از این‌ها نیست. این ایده نامی دارد، اصل مسئولیت واحد، و همان چیزی است که فرق بین کدی که ماه بعد می‌توانید تغییرش دهید و کدی که از دست زدنش می‌ترسید را مشخص می‌کند.

```
    GOOD                          BAD
    ----                          ---
    def calculate_average(s):     def process_student(name, scores):
        return sum(s)/len(s)          validate(scores)
                                         compute(scores)
                                         print_report(scores)
                                         save_to_file(scores)
```

نسخه سمت چپ با یک خط تست می‌شود و هرجایی قابل استفاده مجدد است. نسخه سمت راست بدون دست زدن به فایل‌سیستم تست نمی‌شود.

## مفاهیم اصلی

- **`def` تعریف می‌کند؛ پرانتز صدا می‌زند**
- **پارامتر** نام در تعریف است؛ **آرگومان** مقداری است که پاس می‌شود
- **`return` مقدار را پس می‌دهد و تابع را می‌بندد**؛ `print` فقط نمایش می‌دهد
- **دامنه محلی**: متغیرهای داخل تابع با آن می‌میرند
- **داخل بده، بیرون برگردان**: از `global` پرهیز کنید
- **مقادیر پیش‌فرض** باید بعد از پارامترهای بدون مقدار بیایند
- **آرگومان‌های کلیدی** محل فراخوانی را خوانا و مستقل از ترتیب می‌کنند
- **Docstring** می‌گوید تابع چه کاری می‌کند، نه چطور

## اشتباهات رایج مبتدی

| اشتباه | نتیجه |
|--------|-------|
| استفاده از `print` به‌جای `return` | فراخواننده `None` می‌گیرد و نمی‌تواند با نتیجه حساب کند |
| استفاده از `global` برای تغییر یک متغیر | کار می‌کند، ولی تابع را به همه‌چیز اطرافش گره می‌زند |
| مقدار پیش‌فرض تغییرپذیر (`items=[]`) | آن فهرست بین فراخوانی‌ها باقی می‌ماند و انباشته می‌شود. از `items=None` استفاده کنید |
| پارامتر پیش‌فرض قبل از پارامتر بدون پیش‌فرض | `SyntaxError` |
| فراموشی اینکه `return` فوراً خارج می‌شود | کد بعد از آن هرگز اجرا نمی‌شود |
| نوشتن docstring که فقط نام را تکرار می‌کند | `"""Get the name."""` چیزی اضافه نمی‌کند. بگویید چه برمی‌گرداند |

مقدار پیش‌فرض تغییرپذیر ارزش تأکید دارد، چون واقعاً غافلگیرکننده است:

```python
def add_item(item, basket=[]):   # فهرست یک بار ساخته می‌شود
    basket.append(item)
    return basket

add_item("apple")   # ['apple']
add_item("pear")    # ['apple', 'pear']  ← فراخوانی قبلی نشت کرده
```

## فعالیت‌های کارگاه

۱. **توابع هندسی.** `area_rectangle(w, h)`، `area_circle(r)` و `area_triangle(b, h)` بنویسید. هرکدام عدد بگیرند و عدد برگردانند. هیچ‌چیز چاپ نکنند.
۲. **کمربند ابزار.** `is_even(n)`، `is_positive(n)`، `max_of_three(a, b, c)` و `count_digits(n)` بنویسید.
۳. **بازآرایی.** یک اسکریپت بلند از تکالیف قبلی‌تان را بردارید و به دست‌کم چهار تابع بشکنید. به هرکدام نامی بدهید که کارش را توصیف کند، نه روشش را.
۴. **تمرین docstring.** به هر تابعی که امروز نوشتید docstring اضافه کنید که پارامترها، خروجی و هر فرضی را که دارد بیان کند.

## تکالیف

- **کتابخانه تابع**: پنج تابع کوچک با docstring بنویسید، و اسکریپتی که همه را صدا بزند.
- **پیش‌بینی خروجی**: با توجه به شش تعریف تابع و فراخوانی، دقیقاً بنویسید هرکدام چه چیزی چاپ می‌کند. دست‌کم یک تابع باشد که مقداری را برمی‌گرداند ولی هرگز چاپش نمی‌کند.
- **از شبه‌کد به تابع**: الگوریتم جست‌وجوی خطی از [جلسه ۹](../../module-03-algorithmic-thinking/session-09/README_FA.md) را به تابعی تبدیل کنید که یک فهرست و یک هدف بگیرد و اندیس یا `-1` برگرداند.
- **بازآرایی**: بلندترین برنامه‌تان تا اینجا را بردارید و طوری به توابع بشکنید که هیچ تابعی بیش از حدود ده خط نباشد.

## نکات کلیدی

- `return` برای کد است؛ `print` برای انسان. این دو یکی نیستند.
- متغیرهای محلی با تابع می‌میرند. مقدارها را داخل بدهید، بیرون بگیرید.
- پارامترهای دارای مقدار پیش‌فرض باید آخر بیایند.
- مقدار پیش‌فرض تغییرپذیر یک بار ساخته و بین فراخوانی‌ها به اشتراک گذاشته می‌شود. از آن پرهیز کنید.
- هر تابع یک کار. بقیه نتایج از همین می‌آید.
