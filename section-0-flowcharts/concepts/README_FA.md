## ترتیب مطالعه

درس‌های ۱ تا ۶ را به ترتیب بخوانید. درس ۳ به نمادهای درس ۲ نیاز دارد؛ درس ۴
فرض می‌کند می‌توانید یک انشعاب رسم کنید؛ و درس ۵ فرض می‌کند دست‌کم یک بار نموداری
را خراب کرده‌اید.

## سه الگو در یک نگاه

هر الگوریتمی که تاکنون نوشته شده بافته‌ای از دقیقاً سه الگوست. بوم و یاکوپینی
در سال ۱۹۶۶ ثابت کردند که ترتیب، انتخاب و تکرار دستور زبان کامل محاسبه‌اند — شما
دارید کل زبان را یاد می‌گیرید، و سه کلمه دارد.

```
ترتیب     A → B → C
          گام‌ها به ترتیب، یکی یکی

انتخاب    START → ◇ ──بله──▶ کار ──┐
                 │                ├──▶ STOP
                 └───خیر──▶ (رد) ┘
          لوزی یک مسیر را انتخاب می‌کند

تکرار     START → ◇ ──بله──▶ کار ──┐
                 ▲                  │
                 └──────────────────┘
                 │                  │
                 └───خیر──▶ STOP ◀──┘
          مسیری که به خودش برمی‌گردد
```

## نتایج یادگیری

پس از این شش درس باید بتوانید:

۱. یک فلوچارت معتبر مطابق پنج قانون رسم کنید
۲. سه الگو را در یک الگوریتم ناآشنا تشخیص دهید
۳. چهار اندام هر حلقه‌ای را که می‌بینید شناسایی کنید
۴. یک الگوریتم را روی کاغذ ردیابی کنید و پیش از رسیدن به صفحه اشکالاتش را پیدا کنید
۵. با پنج گام یک مسئلهٔ پرکلمه را به نمودار تبدیل کنید
۶. نمودار ← شبه‌کد ← کد را بدون فکر زیاد تبدیل کنید

## مرجع الگوهای پرتکرار

این جدول را هنگام رسم کنار دستتان نگه دارید.

| کار | الگو | اسکلت |
|-----|------|-------|
| درود گفتن به کاربر | ترتیب | بخوان ← بنویس |
| جمع دو عدد | ترتیب | بخوان، بخوان، جمع، بنویس |
| زوج یا فرد | انتخاب | بخوان ← `N mod 2 = 0 ?` ← بنویس |
| شمارش تا N | تکرار | مقداردهی ← آزمون ← بنویس ← گام ← برگشت |
| جمع یک بازه | تکرار + انباشتگر | `sum ← 0` ← حلقه ← `sum ← sum + i` |
| رمز عبور با تلاش محدود | تکرار + انتخاب + شمارنده | حلقه ← بررسی ← پذیرش / تلاش / رد |

## پیش‌نیازهای بعدی

بخش صفر هیچ پیش‌نیازی ندارد، و هر چیزی بعد از آن به این بخش وابسته است. به‌طور خاص:

- **ماژول ۳، جلسه ۹** این مطالب را با شبه‌کد و تحلیل الگوریتم گسترش می‌دهد. ده
  الگوریتم کلاسیک — fizzbuzz، تست اول بودن، ب‌م‌م، جست‌وجوی دودویی، مرتب‌سازی
  حبابی — آنجا آموزش داده می‌شوند، نه اینجا.
- **ماژول ۴** این نمودارها را به پایتون تبدیل می‌کند. این ترجمه باید مکانیکی باشد.
  اگر سخت به نظر می‌رسد، نمودار تمام نشده بود.
